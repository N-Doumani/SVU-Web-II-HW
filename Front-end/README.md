# مشروع نظام تسجيل الطلاب الديناميكي (BWP501) - الإصدار v3.0

مرحباً بك في الحزمة الثالثة المحسّنة والمكتملة للفرونت إند الخاصة بمشروع المادة.

## 🚀 ما الجديد في الإصدار (v3.0):

1. **بوابة اختيار نمط الدخول (`index.html`)**:
   - صفحة البوابة الرئيسية تمنح المستخدم الخيار الفوري بين:
     - **بوابة الطلاب العاديين**: للانتقال إلى عرض الموقع التفاعلي الشامل (`student_index.html`).
     - **بوابة الأدمن/الإدارة**: للانتقال إلى صفحة الدخول (`login.html`) ولوحة التحكم الإحصائية (`dashboard.html`).

2. **عرض الموقع التفاعلي للطلاب (`student_index.html`)**:
   - **عناصر تفاعلية ثقيلة**:
     - **مخطط الخريطة التفاعلية (Interactive Hotspots)**: نقاط ضوئية نشطة مع نافذة تفاعلية (Popovers) لاستكشاف مباني الحرم والمختبرات.
     - **سلايدر صور سينمائي وديناميكي (Carousel Slider)**.
   - **عناصر تفاعلية خفيفة**:
     - **معرض الصور والميزات المفلتر (Filtered Gallery)**: بطاقات تتفاعل بالحركة عند التحويم (Hover & Tilt) ومعاينة منبثقة (Lightbox Modal).

3. **ملف عميل روابط الـ API جاهز للربط (`js/api_client.js`)**:
   - يتضمن دالّة جاهزة لكل عملية من عمليات الباك إند (`GET`, `POST`) لتسهيل الربط السريع عبر `fetch()` أو `AJAX`.

4. **توثيق الـ API المكتمل (`api_endpoints.json`)**:
   - يحتوي على هيكلية JSON الكاملة لكافة الروابط والـ Request/Response لتسهيل تجهيز الباك إند بلغة PHP.
