==================================================
  Student Registration System - BWP501 Project
==================================================

1. Project Overview:
--------------------
A full-stack dynamic Web Application for managing student registration records, 
built using PHP, MySQL (PDO), Bootstrap 5, JavaScript, and AJAX.

2. Key Features Implemented:
----------------------------
- User Authentication (Register, Login, Logout) with password_hash() security.
- Protected Routes & Session Management.
- Full Student CRUD Operations (Add, View, Edit, Delete).
- Image File Upload Handling for student profile pictures.
- Real-Time Email Validation via AJAX (Fetch API).
- Live Search functionality (by Name, Email, or Phone).
- Server-side Pagination.
- Fully Responsive UI built with Bootstrap 5.

3. Local Setup Instructions (XAMPP):
------------------------------------
1. Move the 'student_project' folder into 'xampp/htdocs/'.
2. Open phpMyAdmin (http://localhost/phpmyadmin).
3. Import the provided 'student_db.sql' file.
4. Verify database connection credentials in 'db.php'.
5. Access the application at: http://localhost/student_project/register.php
